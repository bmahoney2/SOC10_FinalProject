Methods

Introduction:

To predict diabetes risk, we used three models: logistic regression, logistic regression with lasso regularization, and random forests. Importantly, our prediction task is a binary classification problem with no diabetes = 0 and diabetes/pre-diabetes = 1. Since the CDC prepared the data by collapsing pre-diabetes and diabetes into one category, we ran our analysis accordingly using two classifiers.

Logistic regression serves as our baseline model since it predicts binary outcomes while providing highly interpretable results. To select for the most predictive features, we also included a lasso penalty term that selected for only the most predictive features (drove noisy coefficients to zero). We chose L1 (lasso) regularization over L2 (ridge) regularization to identify only the most predictive features in our model. Since L1 enacts a sum of absolute value penalty, whereas L2 enacts a sum of squares penalty term, most coefficients get minimized to zero, thus allowing for only the most predictive features to estimate model output. This decision to use a Lasso model also made the quiz section of this project easier to build and interpret. Lastly, as a robustness check, we included a random forest model to compare the predictive accuracy of our model across different methods.

First, we imported all necessary libraries for our analysis.

Logistic Regression:

Since this is a supervised learning task, we first defined “diabetes_binary” as our target variable. We split the data into an 80/20 train test split, since this partition is popular and standard for most predictive tasks. Then, we trained a logistic regression model that estimates the probability that a given individual has diabetes based on a linear combination of the 21 features. Unlike linear regression, logistic regression restricts outputs between 0-1, which makes the interpretation of probabilistic risk much more intuitive.

# Source: Course Website (adapted code from linear regression)
# make the target variable (diabetes) binary 
data$Diabetes_binary <- as.factor(data$Diabetes_binary)

# Split data into 80/20 train/split
set.seed(123)
splits <- initial_split(data, prop = 0.8, strata = Diabetes_binary)
train_data <- training(splits)
test_data <- testing(splits)

# Fit the logistic regression on ALL features
log_model <- logistic_reg() %>%
  set_engine("glm") %>%
  fit(Diabetes_binary ~ ., data = train_data)

# Predict and compute all probabilities
predictions <- predict(log_model, new_data = test_data)
probs <- predict(log_model, new_data = test_data, type = "prob")

# Compute the Accuracy 
accuracy <- mean(predictions$.pred_class == test_data$Diabetes_binary)

Lasso Regression

Since 16/21 features were statistically significant, we wanted to explore if we could achieve similar results using only the most important features. To do so, we introduced a regularization penalty term to drive most of the coefficients to zero. Since logistic regression is a minimizing objective, introducing a penalty term selects only the most important features. As shown below, we chose a penalty of 0.03 since it produced 9 total coefficients. We believe 9 predictive features is an optimal number to base our interactive quiz off of, since it provides a substantial number of features without being exhaustive. As a result, the 9 most predictive features are: HighBP, GenHlth, HighChol, Age, BMI, HeartDiseaseorAttack, CholCheck, Income, HvyAlcoholConsump.

# Run Lasso Regularization 
lasso_model <- logistic_reg(penalty = 0.03, mixture = 1) %>%
  set_engine("glmnet") %>%
  fit(Diabetes_binary ~ ., data = train_data)

Random Forest Model

As a robustness check, we created a random forest model. Random forests create a sequence of decision trees that can capture non-linear relationships between features and outcomes. As shown in the code below, we fit the random forest model using 500 trees and evaluated their performance using 3-fold cross validation (for timing complexity reasons). We chose these model parameters to optimize for the model accuracy / running time tradeoff. Importantly, we added hyperparameters to strengthen our model. At each split, the model randomly considers between 2 and 10 features (mtry), and a node must have between 2 and 20 observations before it can split further (min_n). We then analyzed which combinations of these hyperparameters resulted in the most accurate model.

# Source: Course Website

# speed up the computation
library(doParallel)
registerDoParallel(parallel::detectCores() - 1)

# create a random forest model
rf_model <- 
  rand_forest(trees = 500, mtry = tune(), min_n = tune()) %>% 
  set_engine("ranger") %>% 
  set_mode("classification")

# define the random forest workflow
rf_wflow <- 
  workflow() %>% 
  add_formula(Diabetes_binary ~ .) %>% 
  add_model(rf_model)

# set up cross validation
diabetes_folds <- vfold_cv(train_data, v = 3)

keep_pred <- control_resamples(save_pred = TRUE, save_workflow = TRUE)

# Define hyperparameters to adjust the model
rf_grid <- grid_regular(
  mtry(range = c(2, 10)),
  min_n(range = c(2, 20)),
  levels = 2
)

# create a resample object
rf_res <- 
  rf_wflow %>% 
  tune_grid(resamples = diabetes_folds, grid = rf_grid, control = keep_pred)

# examine the metrics across folds
collect_metrics(rf_res)
